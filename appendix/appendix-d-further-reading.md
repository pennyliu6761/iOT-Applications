# 附錄 D：延伸閱讀與課程銜接建議

| 主題 | 銜接方向 |
|---|---|
| Wi-Fi 連網（ESP32 / Arduino IoT Cloud） | 讓本學期系統的資料能上傳雲端，實現遠端監控儀表板 |
| MQTT 通訊協定 | 多台裝置之間的資料交換，適合模擬多站點產線通訊 |
| 簡易資料記錄（SD 卡模組） | 長時間記錄感測資料，訓練基礎資料分析能力 |
| 機器學習邊緣運算（TinyML） | 進階選修方向，讓 Arduino 具備簡易異常預測能力 |
| 「AIoT 移動載具研究坊」 | 承接第 9～10 週的超音波避障與馬達控制基礎，進一步發展實體 AGV 專題 |

---

**本課程文件版本**：v1.0　**設計對象**：工業管理系（無電子電路基礎）　**教學平台**：Tinkercad Circuits　**程式語言**：Arduino C/C++（純文字模式）
