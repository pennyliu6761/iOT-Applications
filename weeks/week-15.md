## 第 15 週：期末專案實作與 QA 驗證（Troubleshooting）

### 📌 學習目標
- 獨立完成期末專題的核心功能開發。
- 學會系統化的壓力測試與除錯流程（QA 品質保證思維）。
- 練習程式碼模組化與可讀性優化。
- 為成果展示做最後的體驗優化。

本週沒有固定的「範例程式碼」，而是提供**開發流程檢核表**，引導各組按部就班完成專題。教師角色轉為巡場輔導，針對各組個別問題給予指導。

### 🕐 第 1 小時：核心功能開發檢核表

| 檢核項目 | 說明 |
|---|---|
| ☐ 感測器讀取正常 | 用 Serial Monitor 確認所有輸入元件數值正確無誤 |
| ☐ LCD 狀態顯示正常 | 確認畫面更新沒有殘影或亂碼 |
| ☐ 動力輸出邏輯正確 | 伺服馬達 / 直流馬達動作符合預期角度或速度 |
| ☐ 聲光警示連動正常 | 異常狀態能正確觸發對應的燈光與聲音 |

**參考程式碼片段：功能區塊化寫法範例**

### 🕑 第 2 小時：極端條件壓力測試（QA 品質保證）

**測試情境範例清單**（各組互相測試，記錄發現的 Bug 並修正）：
1. **輸入極端值測試**：可變電阻轉到最左/最右、溫度感測器拉到極高/極低，系統是否維持穩定不當機？
2. **同時觸發測試**：多個輸入條件同時發生（如按鈕與感測器警報同時觸發），系統反應是否符合邏輯優先權設計？
3. **快速連續操作測試**：快速連續按壓按鈕或輸入鍵盤，是否出現彈跳誤判或資料錯亂？
4. **邊界值測試**：門檻值剛好等於臨界點時（例如溫度剛好等於警戒溫度），系統判斷是否符合預期（`>` 還是 `>=`？）

**程式碼模組化重構參考**：

### 🕒 第 3 小時：展示優化

**加分優化項目建議**：

#### 開機迎賓畫面
```cpp
// ============================================
// 開機動畫：LCD 顯示歡迎畫面並發出確認音效
// 這是專業設備常見的「開機自檢（Power-On Self Test）」概念
// ============================================

void showWelcomeScreen() {
  lcd.clear();
  lcd.print("Smart System");
  lcd.setCursor(0, 1);
  lcd.print("Initializing...");

  tone(pinBuzzer, 1000, 100);   // 確認音效（第三個參數為持續時間，會自動停止不需 noTone）
  delay(1500);

  lcd.clear();
  lcd.print("System Ready!");
  delay(1000);
  lcd.clear();
}

void setup() {
  lcd.begin(16, 2);
  showWelcomeScreen();   // 在 setup() 最後呼叫一次即可
}
```

#### 系統閒置省電邏輯
```cpp
// ============================================
// 閒置偵測：長時間無操作，自動降低更新頻率或關閉非必要顯示
// ============================================

unsigned long lastActivityTime = 0;
long idleTimeout = 10000;  // 10 秒無操作視為閒置

void checkIdle() {
  if (millis() - lastActivityTime > idleTimeout) {
    lcd.setCursor(0, 0);
    lcd.print("Idle Mode...    ");
    // 可在此關閉不必要的燈光或降低更新頻率
  }
}

// 提醒：任何偵測到使用者操作的地方（按鈕、鍵盤輸入等），都要記得更新
// lastActivityTime = millis();
```
