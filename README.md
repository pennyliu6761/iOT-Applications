# 物聯網應用實作課程：16 週 Arduino × Tinkercad 教學設計
### 為工業管理系學生量身打造的「零電子基礎、純文字程式」漸進式課程

---

## 課程理念

本課程專為**沒有電子電路基礎、但已具備 Python 等程式邏輯經驗**的工業管理系學生設計，核心原則如下：

| 原則 | 說明 |
|---|---|
| **緩坡堆疊（Scaffolding）** | 每週只新增 1～2 個硬體元件，絕不同時丟出多個新觀念 |
| **單一變數推進** | 每個微型實作只改變一個變數（一行程式碼、一個接線），降低認知負荷 |
| **20 分鐘回饋原則** | 每個「微型實作」控制在 20 分鐘內可看到硬體真實反應，維持成就感 |
| **情境包裝** | 所有元件與程式邏輯，均以「工廠 / 產線 / 倉儲 / AGV」情境包裝，貼近工管系思維 |
| **純文字程式（C/C++）** | 不使用積木式（Blockly）介面，第一週即進入 Arduino IDE 語法，但透過「填空 → 修改參數 → 邏輯擴充」三階段降低門檻 |

**使用平台**：全程使用 [Tinkercad Circuits](https://www.tinkercad.com/) 線上模擬，學生不需要購買實體硬體，且可以在瀏覽器上重複試錯、隨時復原電路，非常適合初學者。

## 如何使用本文件

1. 每週開頭列出**學習目標**、**本週新增元件**、**Tinkercad 接線指引**（文字化步驟，教師可對照 Tinkercad 畫面口頭講解或截圖）。
2. 每個「實作」附上**情境故事**與**完整註解程式碼**（註解採「工業邏輯語言」而非單純「腳位語言」，強化工管系的流程思維）。
3. 每週最後附上 **🌶️ 進階挑戰題**，供學有餘力的同學挑戰，不列入基本進度要求。
4. 每個檔案內都有「上一週 / 下一週 / 回目錄」導覽連結，方便在 GitHub 上瀏覽切換。
